# games/doom

- `js-dos/` — [js-dos](https://js-dos.com) 8.5.0 runtime (DOSBox compiled to WebAssembly), **GPL-2.0**, vendored unmodified
  from the npm package `js-dos`; only the DOSBox backend files are kept. Source: https://github.com/caiiiycuk/js-dos
- `doom-19sw-v4.jsdos` — a js-dos bundle containing the **complete, unmodified DOOM 1.9 shareware package**
  (id Software, 1995; freely redistributable as a whole) plus a `DEFAULT.CFG` (Sound Blaster + OPL music, left-Shift run)
  and a `.jsdos/dosbox.conf` that boots `DOOM.EXE -nomouse`. Nothing from the registered game is included.
