**Phase start:** `e768c09` (RD-09 closed). **Build:** `eeaf105` phone layout + canvas tab stop + switch removal.

## What the build did (for the panel)

- **Phone (≤ 760 px):** the lanes are one row of 44 px colour dots (name = aria-label, a muted dot hollow; the M lamps
  leave the face); the console is **play + bar·beat + 2×4 knobs + 2×8 cells** — fill, fill next, throw, the filter and
  the action words leave it (`display: none`; find still **runs** the hidden ACTIONS — `findHidden` exempts them — and
  the Move keeps every hold); play moved from C1's floating thumb-zone ring **into the console** (it floats again only
  in focus mode, where the console hides); the peek sits fixed top-left over the canvas on narrow windows (it was
  `display: none` ≤ 1100 before); the quest drop-down opens **upward** on a phone (below the pills it fell past the
  last scroll line); pills one line and the full-height bottom sheet were already in (RD-7 / RD-3).
- **Canvas as one tab stop:** `#cv` moved in the DOM to just after the console (fixed, z 0: zero pixel change; play
  stays the page's first Tab), `tabindex=0 role=application aria-roledescription=orbit`, named per bar ("rings: 4
  lanes, aligns in 5 beats"), keys described (`#cv-keys`); ↑↓ pick the lane, ←→ walk its steps (the cells turn to that
  page, as Back + step pins it), Enter is the planet-tap cycle (off → on → accent); each move spoken through
  `#announce`; a white 2 px ring round the focused tick (scene's held halo, `focus: true`), keyboard only
  (`:focus-visible`). Locks stay on the cells' step page (Alt+Enter on a cell opens it).
- **Clean-up:** the simple / everything switch (I7) removed end to end (`setView`, `quests.view`, `PLAIN` /
  `paramLabel` / `startView`, `body.simple`, `.adv`, `#view-mode`, the help table's `data-word` spans); an RD-9 save's
  `view` key is ignored on load; orphan ids `gen-block`, `midi-artic-note` dropped; `test/access.test.js` guards the
  canvas stop, the Tab order, the phone CSS and **zero orphan ids** (scan over src + styles + tools + tests + the
  page's own aria references, dynamic allowlist `pg-rhythm` / `pg-sound`).
- **Tools:** `face-audit.mjs` now treats `#cv` as the stage, not a control (it is what A1 / A5 / NIGHT compare controls
  against), exempts the DECISION-stripped console ids from IDS on phone sizes only, and dismisses the transient
  first-visit toast before measuring; `console-check` / `find-check` / `session` single-view; **new
  `tools/access-check.mjs`** = the scripted A4 walk.

### Known judgement calls for the panel

1. The **lane head** (voice, page tabs, step tools, MOVE⇢ chip) stays on the phone console though DECISION's phone row
   lists only "play + bar·beat, 2×4 knobs and 2×8 cells": it is the cells' header and the only route to the sound /
   step pages and the step page's "done / more…" on a phone without a Move or keyboard.
2. On a phone without a Move, **fill / fill next / throw / jam have no touch route** (they are holds / not ACTIONS, so
   find cannot run them); undo, randomize, share, init and the rest still run from find.
3. The first-visit demo **toast covers the cells for ~2.4 s** on a phone (transient, pointer-events none); the face
   audit dismisses it before measuring.
4. Hidden quests (× on the quest pill) have **no un-hide route** any more (switching to simple used to bring them
   back); the title now says "progress is kept".
