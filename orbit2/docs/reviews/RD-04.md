What the phase changed:
- **Find** (`src/poly/find.js`, pure; `app.js` "RD-4 find"): ⌘K / Ctrl+K and `/` (from anywhere but a text field or a
  select; not while the help or gift card is open) open the sheet with the cursor in `#find`, a combobox over a listbox
  at the top of the sheet (shown only while the sheet is open; the list lies over the body, nothing moves). The index is
  read off the page each time find opens (`buildFindIndex`): every `button, select, input, textarea, summary, a[href],
  [role=slider|tab|radio|switch|checkbox]` outside the find box, the dialogs and the canvas, not hidden for a reason the
  sheet can't undo (a `hidden` ancestor other than a pane / the sheet body; display none on the control itself, e.g.
  steps 17–32 of a 16-step lane), with an accessible name (aria-labelledby, aria-label, its label without the options,
  its text, its title; the state after the first comma dropped: "step 3, on, accent" → "step 3"); where it lives (tab ·
  drawer · group) and a select's options are searchable too. Synonyms: 55 groups (plain ↔ technical: hits ↔ euclid,
  shift ↔ rotation, speed ↔ ratio, chance ↔ probability, stems ↔ multitrack, meter ↔ time signature, …) seeded from
  Greta's and Rio's feature tables. Actions (`ACTIONS`, 22 button ids: play, undo, redo, tap tempo, share, help, focus,
  init, randomize, wild, save, load, clear lane, reset phase, export WAV / stems / MIDI / kit / all, copy link, share
  audio / postcard): Enter presses them (outside the sheet the sheet goes back as it was); every other result is shown
  (its tab, its drawers; simple view gives way to everything for a tucked control) and focused with the keys its own.
  Ranking: name word 6 / 5 (whole / start) > synonym of the name 4 / 3 > where / extra 2 / 1, +1 when the query says
  the whole name; ties → actions → recents → shorter name → page order; at most 8. Empty query = recents
  (`midi-warz.orbit2.find`, 6, any bad saved value = none) then 7 defaults. ↑↓ pick, Enter runs, Esc empties the field
  and an empty field's Esc is the Esc order's.
- **One Escape** (`escStep` in `find.js`, `escapeOnce` in `app.js`): one window handler replaces the old two (blur on
  Esc; keys-pop + focus mode). Order: popup (share menu, slot menu, ring menu) → step page (the lock panel, while drawn)
  → sheet → focus mode → give the keys back (blur). One layer per press; only what is open and drawn counts. A modal
  card (help, gift) closes itself; a text field owns its Esc (B8); a popup's own Esc handler answers first when the
  focus is in it.
- **Empty canvas** (`cv` pointer events): a press off the rings released within the drag slop = one `escapeOnce()`; a
  press that closed a popup does nothing more; never an edit (no model call on that path).
- **The sheet is closed on load** at every size; only the tab is remembered (`{ tab }`); an RD-3 save with `open: true`
  still loads (closed, its tab kept). The tab arrows and tab clicks open it as before.
- `index.html`: the find box, the help table's ⌘K / `/` and Esc rows. `styles.css`: `.find`, `.find-list` (tokens,
  13 / 11 px, the picked row a 2 px `--l` outline). `README.md`: the RD-4 line. `__poly`: `openFind`, `findIndex`,
  `escapeOnce`, `escState`.
- **Tests and tools**: `test/find.test.js` (7 tests: the synonyms test in both views, A4's 4-key path, ranking tiers and
  ties, words, recents, the Esc order as a pure function, static guards: every action a button on the page, the
  selector covers every interactive role the page sets, one window Esc handler). `tools/find-check.mjs` (the browser
  check below; exit 1 on a failure).

### Fixes from the browser check

- **Steps 17–32 of a 16-step lane** were in the index (display none: outside the lane's page), so find listed controls
  that can't be shown → a control whose own `display` is none is out (`.adv` excepted: find unlocks it).
- **"euclid"** ranked the euclid-mask radios ("AND", "XOR", found by their where) above the hits knob → a synonym of
  the name is its own tier above where words.
- **"st" / "tempo" / "bpm"**: "play / stop" took "st" from export stems, "tap tempo" took "tempo" and "bpm" from the
  tempo knob → play is named "play" (stop is an extra word), and +1 when the query says the whole name, one-word
  synonyms included (a phrase like "tap tempo" doesn't make "tap" a tempo).
- (tool) the COVER pass first built the index with the sheet closed and before switching view, so × and the evolve
  scope radios (re-rendered in the view's words) looked missing → it builds the index as `openFind` does, per view.
- (tool) on the phone, focus mode makes the canvas the window, so the old empty spot landed on a ring (a tap = an
  edit) → the empty spot is looked for again after F.

the step page is today's lock panel until RD-6; pills (RD-7) are not an Esc layer.
