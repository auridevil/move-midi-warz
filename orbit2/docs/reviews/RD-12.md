## What shipped (for the panel)

- **Kit ▾ on the console's lane head**, right of the lane's voice ▾ and styled the same (`class="hair"`,
  `aria-label="kit (all lanes)"`, title "Every lane's sound at once; the pattern stays"), listing every kit from
  `kits.js` plus "custom" when the lanes no longer match one (B3). The id `kit-select` is kept, so old selectors and
  the RD-1 baseline id gate still find it. The sheet's lane-tab duplicate (`<label>kit (all lanes)…`) is removed.
- **One path for every route**: the select, Move Shift + ◀ ▶ (`cycleKit`) and a ⌘K pick all land in `applyKit` —
  one `sync()` = one undo step, one setlog action (`slog.act('kit', before, after, { absorb: true })`: absorb, or the
  pattern diff would log the same change twice), and the peek says "kit · name" for 400 ms by the knob-touch path
  (`peekKit` → `paintPeek`, never hover; a knob touch takes the peek over). The console-log overlay's status line
  already named the kit (`kit <name>`, RD-5).
- **A5 stays at 50 — the trade the panel should check.** The face has been AT the 50 cap since RD-5 (the decision's 48
  + the quest card's 2, recorded in RD-05's review). The decision's RD-12 row budgets the kit inside ≤ 50, so one slot
  had to come back: on wide windows the quest card's × folds into the quest's own drop-down
  (`data-folded-into="quest-go"`, the share-"…" precedent at `styles.css` ~343), where a **hide** button joins show me
  / skip (keyboard, mouse and touch; Sheet → setup → settings stays the way back). Narrow windows and the phone keep
  the ×.
- **⌘K ranking fix (`find.js`), needed for "⌘K kit lands on the console control":** the export-kit ACTION used to
  outrank the kit select on the query "kit" (ties go to actions). The whole-name bonus now judges the name's words
  outside parentheses ("kit (all lanes)" → "kit"), and a multi-word synonym phrase fully covered by the query counts
  ("drum rack" says "kit"). Pure, unit-tested; the old bonus cases ("tempo" vs "tap tempo", "bpm") are unchanged and
  still covered by `find.test.js`.
- On phones the kit rides with voice ▾ into the sheet's lane drawer (`ph-voice`, the RD-10 pattern). The keys & mouse
  help table names the lane head's selects; the Move table's Shift + ◀ ▶ row and the "?" drawing ("voice · ⇧ kit")
  were already right.
- Tests: `test/kit.test.js` (the fixture lane JSON the old sheet control produced, B3 custom/re-apply, the ⌘K
  queries, static guards, the A5 fold). Browser: `tools/kit-check.mjs` — FACE / CLICK / CMDK / MOVE / B3 / UNDO /
  PHONE, all pass (run it with `--assert`, ports 5400/9400).
